# Profi Reply Bot

Telegram-бот: текст или скриншот объявления → персональный отклик до 500 символов.

## Возможности
- Текст, фото, PNG/JPEG/WebP как документ до 10 МБ. Каждое изображение в альбоме обрабатывается отдельно.
- Вакансии: предупреждение вне цитаты и отдельный готовый отклик о сотрудничестве.
- Основной ответ оформлен Telegram-цитатой. До 256 символов — кнопка копирования; длиннее — кнопка открывает отдельный моноширинный блок, который можно скопировать средствами Telegram.
- SQLite: ID, username, имя, первый/последний источник, даты, обращения, успешные ответы, ошибки, классификация вакансий, вызовы ИИ и токены.
- Источники только по ссылкам `https://t.me/BOT_USERNAME?start=ad_01`. Telegram не сообщает, из какого канала пришёл человек без параметра start. Пользователь учитывается после первого сообщения/нажатия Start, не просто открытия страницы бота.
- Админка внутри Telegram: `/admin`, `/users`, `/user ID`, `/sources`, `/source ad_01`, `/export`, `/profile`, `/set_profile полный текст`, `/block ID`, `/unblock ID`.
- Профиль преподавателя общий для бота. Первоначально Константин, информатика/программирование; акция до 25.10.2026. Подтверждённые регалии добавляются через `/set_profile`.
- `/usage`, `/privacy`, `/delete_data` для пользователей.

## Запуск Docker
1. Скопируйте `.env.example` в `.env`.
2. Заполните BOT_TOKEN, OPENAI_API_KEY, ADMIN_CLAIM_CODE случайной строкой (например, `python3 -c 'import secrets; print(secrets.token_urlsafe(24))'`). Не публикуйте `.env`.
3. `docker compose up -d --build`.
4. Откройте личную ссылку `https://t.me/BOT_USERNAME?start=admin_ВАШ_КОД`, нажмите Start. Первое успешное применение назначает владельца, повторное другим пользователем не работает. Альтернатива — ADMIN_IDS с известными Telegram ID через запятую.
5. Откройте `/admin`.

## Railway
Разверните каталог с Dockerfile в отдельном проекте. Добавьте переменные из `.env.example` и постоянный Volume с точкой монтирования `/data`. Только ОДНА реплика: бот получает обновления long polling. HTTP-домен не нужен. Healthcheck `/health`, порт PORT (по умолчанию 8080). Без постоянного тома база пропадёт при пересоздании контейнера. Не запускайте одновременно локальную и серверную копии с одним токеном.

Если на токене уже настроен webhook, приложение остановится, не удаляя его. Сначала проверьте и остановите прежний бот, затем переключите способ получения обновлений осознанно.

## Локально
Python 3.11+ с системной базой часовых поясов, сторонние Python-пакеты не требуются. Передайте секреты через окружение и выполните `python3 app.py`. Дополнительно поддерживается SECRETS_FILE с путём к приватному JSON-объекту переменных. `.env` читается Docker Compose, а не самим Python.

## Лимиты и данные
По умолчанию 30 вызовов ИИ на пользователя и 300 суммарно в сутки по Москве. Один отклик обычно требует один вызов, при превышении 500 символов — до двух. Ошибочные вызовы тоже занимают квоту, чтобы ограничивать повторные расходы. Очередь обрабатывается последовательно; это небольшой стартовый бот, не система для массовой нагрузки.

OpenAI Responses API, модель gpt-4.1-mini, структурированный JSON, `store:false`. Исходные изображения не записываются на диск. Входящие обновления находятся в очереди БД до обработки; затем содержимое очищается. Готовые ответы очищаются через 7 дней, события через 180 дней, агрегаты — по запросу удаления. Копирование сохранённого ответа доступно только его автору. `/delete_data` удаляет пользовательскую запись и связанные запросы, но не сообщения из Telegram и не данные у внешнего API. Права администратора сохраняются независимо от удаления истории.

Оценки и суммы расходов в валюте не рассчитываются; админка показывает токены. Для лимита расходов также настройте бюджет проекта OpenAI.

Перед обновлениями сохраняйте резервную копию SQLite штатным `.backup` или Python `sqlite3.Connection.backup()`, а не копированием только основного файла при активной WAL.

## Проверка
`python3 -m unittest discover -s . -v`

Проверяются атрибуция и дедупликация, доступ администратора, атомарная квота, удаление, доступ к копированию, HTML-экранирование, ограничение длины, вход изображений в API, восстановление после перезапуска.

Секреты и рабочая база не входят в архив исходников.
