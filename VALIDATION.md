# Проверка редактора системного промпта

22.10.2026: `python -m unittest discover -v` — 26 тестов прошли; 11 интеграционных проверок PostgreSQL пропущены без TEST_DATABASE_URL. Рабочая база в тестах не использовалась.

Проверены права администратора для команд и кнопок, сохранение без вызова ИИ и расхода лимита, применение к обычным ответам и вариантам, текстовые файлы через имитацию Telegram, пустой и слишком длинный ввод, отмена и подтверждение сброса. Сохранение после повторного открытия базы проверено на SQLite. Остальные проверки покрывают форматирование, лимиты, фото, очередь webhook и повторную доставку.

Онлайн-публикация этого обновления не выполнена: GitHub отклоняет запись с ошибкой 403 Resource not accessible by integration. Новые возможности доступны после замены app.py и transport.py и запуска деплоя.
